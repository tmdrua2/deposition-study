      기초

      장비를 이해하기 전에 알아 둘 세 가지. 장비 페이지에서도 이 페이지로 이어집니다.

        장비사 · 실습 기록

        어떤 회사가 증착 장비를 만드는지, 그리고 직접 해 본 공정 기록.

          사이트 소개

          증착(Deposition) 장비사 취업을 준비하면서 공부한 내용을 정리하는 개인 학습 노트입니다. 장비마다 분해 연출로 전체 구성을 먼저 보고, 원리 → 장비 구성 → 공정 흐름 → 공정변수 → 문제와 점검 → 면접 질문 → 출처 순서로 읽도록 짰습니다.

          사실 정보에는 출처를 답니다. 직접 열어 확인한 자료만 주소와 확인 날짜를 적고, 장비나 조건에 따라 달라지거나 확실하지 않은 내용에는 검증 필요 표시를 붙였습니다. 특정 회사 장비의 사양이나 구체적인 수치는 싣지 않고, 그림은 대표적인 300mm 장비 구성을 단순하게 그린 것입니다.

          LAYER BY LAYER — 막이 한 층씩 쌓이듯, 공부도 한 층씩.
