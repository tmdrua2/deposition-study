# PECVD 본문 개편 계획 (2026-11-22)

## 목표
장비 분해 무대 아래 본문(숫자 목차 + 단순 글)을 **7개 섹션 카드 + 섹션별 하위 페이지**로 바꾼다.

## 구조
- `equipment/pecvd.html` 본문 = 섹션 카드 7개 (원리 / 장비 구성 / 공정 흐름 / 공정변수 / 문제와 점검 / 면접 질문 / 출처).
  카드 순서 = CLAUDE.md "장비 페이지 틀" 순서. 카드에 예전 h2 id(`principle` 등)를 그대로 붙여 옛 주소도 동작.
- 하위 페이지: `equipment/pecvd/<id>.html` (principle, hardware, flow, parameters, troubleshooting, interview, sources).
  `data-root="../../"`. 각 페이지 = 남색 머리(큰 제목) + 크림 본문 + 이전/다음·장비로 돌아가기.
- 섹션 목록은 `js/sections.js` 한 곳에만 (이전/다음·진행 표시를 여기서 만듦).

## 디자인
- 카드 묶음은 크림 본문 안에 둥근 **남색 창**(코랄 빛 + 세로 골유리) — 장비 무대를 다시 들여다보는 창. 큰 제목이 창 위에 얹힘.
- 카드 = 반투명 유리. 마우스를 올리면 살짝 확대 + 청록 외곽선 (장비 모듈과 같은 느낌). 번호(01~07)는 공부 순서라서 씀.
- 원리 페이지: 아임웹식 — 글 단계가 스크롤되면 고정된 단면 애니메이션이 그 단계로 바뀜. 이 구간만 남색 배경.
  휴대폰: 그림이 위에 고정, 글이 아래로 지나감.

## 애니메이션 (원리)
- `js/sim/sim-core.js` 재사용 + 작은 확장: 단계를 밖에서 고르는 `setStage()`, 장면별 색 변수 `scene.colors`.
- `js/sim/pecvd.js` 장면: ① 가스 유입 ② 플라즈마 속 분해(라디칼) ③ 흡착·막 성장 ④ 부산물 배기.
- 단계 전환은 IntersectionObserver(GSAP 불필요). 움직임 줄이기·`?still=1` → 단계마다 정지 그림.

자체 검토 체크리스트(CLAUDE.md) + 1440×900·1280×720·390×844 캡처, 스크립트 오류 0.
