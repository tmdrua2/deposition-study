# 메인 표지(index.html) 개편 — 방향 시안

시안 파일: `docs/mockups/cover-a.html`, `docs/mockups/cover-b.html` (브라우저로 직접 열기)
캡처(1440×900): `docs/mockups/cover-a-1440.png`, `docs/mockups/cover-b-1440.png`
두 시안의 공통 부분: 카드 겉모양 `docs/mockups/lineup.css`, 그림 `js/home.js`, 실루엣 데이터 `data/lineup.js`, 색 변수 `--tone-*`(`css/style.css`)

## 공통
- 바탕은 중립 크림·연회색(`--cover-bg`). 장비 카드마다 고유 색 톤 그라데이션 + 세로 골유리 + 아래쪽 빛 번짐
- 색: PECVD 남색 + 코랄 빛 / ALD 하늘 / PVD 카키 / **Epi 청자(셀라돈) 제안** / **ECD 구리 제안**
- PECVD 카드는 장비 페이지와 같은 데이터·렌더러로 그린 아이소메트릭 그림. 준비 중 장비는 같은 렌더러로 그린 단순한 형태를 무채색 반투명 실루엣으로
- 마우스를 올리면 표지 바탕이 그 장비 색으로 서서히 물들고(CSS `:has`), 카드는 살짝 커지면서 외곽선이 생김
- PECVD만 링크. 준비 중 카드는 누를 수 없고 "준비 중"으로 표시
- 아래로 스크롤하면 기초 → 장비사·실습 기록 → 사이트 소개 (고른 뒤에 만듦)

## 시안 A: 베이 진열
- 높이가 같은 칸 5개가 한 바닥선 위에 나란히 섬. PECVD 칸은 두 배 가까이 넓음
- 위쪽: 왼쪽에 큰 한글 이름 + 영문 이름, 오른쪽에 한 줄 소개 + 검색창
- 성격: 차분하고 정돈된 느낌, 장비 5종을 고르게 비교해 보기 쉬움. 휴대폰에서는 칸이 가로 2열 또는 세로로 쌓임

## 시안 B: 워드마크 무대
- 화면 폭을 채우는 영문 워드마크(외곽선 글자) 위로 큰 PECVD 무대가 겹쳐 올라옴. PECVD 장비 페이지의 "큰 글자 뒤 장비" 연출과 같은 말투
- 준비 중 장비는 오른쪽에 가로 띠 4개로 쌓여 차례를 기다림
- 성격: 완성된 PECVD가 주인공이 되는 강한 첫인상. 검색창은 워드마크 위 줄로 옮길 예정(시안에는 없음)

## 영문 이름 후보
1. DEPOSITION NOTES: 뜻이 가장 바로 읽힘 (시안에 넣은 이름)
2. LAYER BY LAYER: 막이 한 층씩 쌓이는 증착을 그대로 담은 말. 공부도 한 층씩 쌓는다는 뜻
3. FILM & CHAMBER: 무엇을(박막) 어디서(챔버) 만드는지를 짝지은 이름. 장비 중심 사이트라는 성격이 드러남
