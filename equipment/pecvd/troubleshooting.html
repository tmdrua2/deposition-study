PECVD 장비로 돌아가기

05/ 07Troubleshooting

문제와 점검

증상에서 출발해 범위 → 시점 → 원인 후보 → 확인 → 조치 순서로 좁혀 갑니다. 현장 CS 엔지니어가 머릿속으로 그리는 점검 흐름도입니다.

    모든 문제에 쓰는 네 칸 점검 틀

    증상이 달라도 처음 몇 단계는 같습니다. 부품부터 뜯어보지 않고, 먼저 범위와 시점으로 의심할 곳을 좁힙니다.

    1. 한 곳만인가? 한 챔버(PM)에서만 생기면 그 챔버의 부품, 여러 챔버에서 함께 생기면 함께 쓰는 것(레시피·가스 공급·이송 경로·측정 장비)을 봅니다.
    2. 갑자기인가, 서서히인가? 갑자기 생겼으면 그 시점에 있었던 일(정비·부품 교체·세정·레시피 변경·알람)을, 서서히 나빠졌으면 쌓이거나 닳는 것(막 쌓임·막힘·마모·센서 드리프트)을 봅니다.
    3. 원인 나누기 — 가스·RF·배기·웨이퍼 중 어느 길의 문제인지(장비 구성의 계통도), 로그와 측정 결과로 후보를 하나씩 지웁니다.
    4. 조치와 확인 — 고친 뒤 테스트 웨이퍼로 결과가 돌아왔는지 확인하고, 원인과 조치를 기록합니다.

    웨이퍼가 지나는 길은 진공 쪽(PM·TM·LL)과 대기 쪽(EFEM·FOUP)이 다릅니다. 파티클처럼 길 전체가 원인이 될 수 있는 문제는 두 쪽을 따로 나눠서 봅니다. 아래 흐름도는 대표적인 점검 순서이고, 실제 순서와 판단 기준은 장비·회사마다 다릅니다 검증 필요.

    문제와 점검 순서

    증상을 누르면 점검 흐름도가 펼쳐집니다. 원인 후보의 부품 이름을 누르면 장비 페이지에서 그 부품 패널이 열립니다.

    A막 두께 이상 · 균일도 나쁨두께가 목표에서 벗어남, 웨이퍼 안 두께 차이가 큼

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 언제부터, 어느 PM에서 나왔나요?
    • 두께 자체가 벗어났나요, 웨이퍼 안 차이(균일도)가 커졌나요? 균일도 맵 모양(가운데 두꺼움 / 가장자리 두꺼움 / 한쪽 치우침)은요?
    • 최근 정비·부품 교체·RPS 세정·레시피 변경이 있었나요?
    • 같은 측정 장비로 잰 값인가요?
    • RF 반사 전력·압력·유량 알람 기록이 있나요?

    1. 01 · 범위

      한 챔버만인가, 여러 챔버인가

      한 챔버만 → 그 챔버의 히터·샤워헤드·간격·펌핑 링, 그 챔버로 가는 가스 라인(MFC)과 RF 쪽

      여러 챔버 → 함께 바뀐 레시피, 공용 가스 공급(레귤레이터 공급 압력), 측정 장비 자체 검증 필요

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 정비·부품 교체 직후(간격·평행이 틀어졌는지), RPS 세정 직후(시즈닝), 그때 난 알람

      서서히 → 쌓이고 닳는 것: 샤워헤드 구멍 막힘, 펌핑 링·배기 막힘, MFC 드리프트(시간이 지나며 어긋남), 온도 센서

    3. 03 · 원인 후보 → 확인 → 조치

      균일도 맵의 모양과 최근 PM·세정 이력을 함께 보고 좁힌다

      • 샤워헤드–히터 간격·평행 공정 챔버 패널

        확인 한쪽 치우침 맵이면 가장 먼저 의심. 간격과 평행(레벨링)을 잰다

        조치 레벨링 다시 맞춘 뒤 테스트 웨이퍼 검증 필요

      • 히터 온도 분포 공정 챔버 패널

        확인 영역별 온도 읽음값과 열전대(온도 센서) 상태

        조치 센서·히터 점검, 필요하면 교체 검증 필요

      • 샤워헤드 구멍 막힘 샤워헤드 패널

        확인 얇아진 영역이 특정 구멍 영역과 겹치는지, 마지막 세정 이후 처리량, 떼어서 육안·빛 투과 검사 검증 필요

        조치 세정, 복구되지 않으면 샤워헤드 교체

      • 펌핑 링 막힘 (배기 쏠림) 공정 챔버 패널

        확인 배기가 한쪽으로 쏠리지 않았는지, 스로틀 밸브 열림 값이 평소보다 많이 열려 있는지

        조치 펌핑 링·배기 경로의 쌓인 부산물 제거 검증 필요

      • MFC 유량 가스 박스 패널

        확인 표시값과 셋포인트(목표값) 차이, 밸브 구동 값 추이, 가스를 끈 상태의 영점, 유량 검증(압력 상승 속도로 실제 유량 재기) 검증 필요

        조치 MFC 보정 또는 교체 후 테스트 웨이퍼

      • RF 반사 전력 RF 전원 장치 패널

        확인 반사 전력과 매칭 튜닝 위치가 평소와 다른지

        조치 다르면 C. 플라즈마 이상 흐름으로

      • 세정 직후 첫 몇 장만 다름 공정 챔버 패널

        확인 시즈닝을 정해진 대로 했는지, 세정 종료 판정이 정상이었는지, 몇 장 뒤 평소 값으로 돌아오는지 검증 필요

        조치 시즈닝 레시피 확인, 같은 레시피의 다른 PM과 세정 직후 첫 장 비교

    4. 04 · 조치 후 확인

      테스트 웨이퍼로 두께·균일도를 다시 잰다

      같은 레시피의 다른 PM과 비교해 평소 수준으로 돌아온 것을 확인한 뒤 생산을 다시 시작하고, 원인과 조치를 기록합니다.

    B파티클 증가웨이퍼 위 입자·결함 수가 평소보다 많음

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 파티클 맵에서 어디에 몰리나요? (가장자리 / 특정 위치 / 전체)
    • 장비에 들어가기 전 측정값과 비교했나요? (들어올 때부터 있었는지)
    • 어느 PM을 거친 웨이퍼인가요? 공정 없이 이송만 한 웨이퍼도 늘었나요?
    • 마지막 RPS 세정 뒤 몇 장째인가요? 최근 챔버를 연 정비가 있었나요?
    • 파티클 크기·성분 분석 결과가 있나요?

    1. 01 · 범위

      한 챔버만인가, 웨이퍼가 함께 지나는 길 전체인가

      한 챔버만 → 그 PM 안: 벽·샤워헤드에 쌓인 막 벗겨짐, 리프트 핀, 슬릿 밸브·뚜껑 오링(고무 밀봉)

      여러 챔버 · 모든 웨이퍼 → 함께 지나는 길. 진공 쪽(TM 이송, LL 펌핑·벤트)과 대기 쪽(EFEM의 FFU·로봇)을 나눠, 공정 없이 이송만 한 웨이퍼로 어디서 붙는지 찾는다. 공용 가스 라인 필터도 후보

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 정비로 챔버를 연 뒤, 오링·부품 교체 뒤, 펌핑·벤트 속도 설정 변경, 배관 작업 뒤 퍼지 부족

      서서히 → 세정 뒤 처리량이 늘수록(쌓인 막이 두꺼워져 벗겨짐), 오링·블레이드 패드 마모

    3. 03 · 원인 후보 → 확인 → 조치

      파티클이 몰리는 위치와 "어디를 거친 웨이퍼인지"로 좁힌다

      • 벽·샤워헤드에 쌓인 막 벗겨짐 샤워헤드 패널

        확인 마지막 RPS 세정 이후 처리량 — 벽·샤워헤드에 쌓인 막이 벗겨지는지

        조치 RPS 세정, 세정 주기 조정 검증 필요

      • 기체 속 반응 조건 공정변수 페이지

        확인 압력·전력 조건이 기체 속 반응으로 파티클이 생기기 쉬운 쪽인지, 레시피와 같은지

        조치 레시피 값, 스로틀 밸브·MFC 실제값 점검

      • 리프트 핀·이송 긁힘 공정 챔버 패널

        확인 리프트 핀·웨이퍼 이송 중 긁힘, 웨이퍼 뒷면 상태

        조치 핀 높이·끝 마모 점검, 필요하면 교체 검증 필요

      • 슬릿 밸브·뚜껑 오링 공정 챔버 패널

        확인 오링 마모, 여닫을 때 닿는 면

        조치 오링 교체 뒤 리크 체크(누설 점검)

      • 진공 쪽 이송: TM 트랜스퍼 모듈 패널

        확인 TM에 들어갔다 나오기만 한 웨이퍼로 재서 이송 탓인지 공정 탓인지 나눔, 블레이드 패드 오염

        조치 블레이드 패드·표면 청소, 슬릿 밸브 오링 점검

      • 진공 쪽 이송: LL 로드락 패널

        확인 LL을 거치기만 한 웨이퍼로 확인, 벤트·펌핑 속도 설정, 벤트 N2 필터·디퓨저

        조치 속도 설정 복구, LL 바닥·선반 청소

      • 대기 쪽: EFEM EFEM 패널

        확인 EFEM만 돌린 웨이퍼로 확인, EFEM 내부 차압(양압), FFU 팬·필터

        조치 멈춘 팬·막힌 필터 교체, 문·패널 닫힘 확인

      • 가스 라인 가스 박스 패널

        확인 특정 가스를 켤 때만 늘어나는지(가스 스틱을 하나씩 좁혀 감), 필터 앞뒤 압력 차이, 배관 작업 뒤 퍼지

        조치 필터 교체, 충분히 퍼지

    4. 04 · 조치 후 확인

      파티클 측정용 웨이퍼로 다시 잰다

      장비에 넣기 전과 뒤를 비교해 늘어난 양을 확인합니다. 챔버를 열었다면 리크 체크와 시즈닝을 마친 뒤 확인합니다 검증 필요. 아킹 흔적이 보이면 C. 플라즈마 이상도 함께 봅니다.

    C플라즈마 이상점화 실패 · 반사 전력 높음 · 아킹(불꽃 방전)

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 알람 이름과 시각은요? 점화 순간 / 공정 중간 / 특정 레시피 단계 중 언제인가요?
    • 반사 전력과 매칭 튜닝 위치 로그를 볼 수 있나요? 평소 값과 비교하면요?
    • 최근 RF 케이블·매칭·샤워헤드 같은 부품을 바꿨나요? 레시피를 바꿨나요?
    • 마지막 RPS 세정은 언제였나요?
    • 아킹이라면 웨이퍼에 자국(결함 맵)이 있나요?

    RF 쪽을 손으로 점검할 때는 전원 차단·잠금(LOTO) 뒤에 합니다.

    1. 01 · 범위

      한 챔버만인가, 여러 챔버인가

      한 챔버만 → 그 PM의 RF 경로(제너레이터 → 케이블 → 매칭 → 전극)와 챔버 안 상태

      여러 챔버 → 함께 바뀐 레시피 조건(압력·가스), 공용 설비 검증 필요

    2. 02 · 시점

      언제 나는가, 갑자기인가 서서히인가

      점화 순간 → 점화 단계의 압력·가스, 매칭 시작 위치(프리셋) 검증 필요

      공정 중간 · 특정 단계 → 그 단계의 압력·가스 변화, 챔버 안 쌓인 막

      갑자기 / 서서히 → 갑자기: 부품 교체 뒤 체결·정합 범위 / 서서히: 튜닝 위치가 조금씩 끝으로 움직임(챔버 상태 변화)

    3. 03 · 원인 후보 → 확인 → 조치

      챔버 조건 → RF 연결 → 챔버 안 → 마지막에 RF 장치 자체 순서로

      • 압력·가스 조건 가스 박스 패널

        점화 실패반사 전력아킹

        확인 압력·가스 유량이 레시피대로인지 — 챔버 조건이 바뀌면 플라즈마 임피던스가 바뀜

        조치 압력(스로틀 밸브)·유량(MFC) 쪽 원인부터 해결

      • 매칭 튜닝 위치 RF 전원 장치 패널

        반사 전력점화 실패

        확인 커패시터 위치가 평소 값·다른 PM과 비교해 끝에 붙어 있는지(정합 범위를 벗어남), 왔다 갔다 하는지(헌팅)

        조치 끝에 붙었으면 챔버 조건 변화부터, 헌팅이면 플라즈마 안정성·튜닝 속도 설정, 모터·커패시터 구동 점검

      • RF 케이블·커넥터 RF 전원 장치 패널

        점화 실패반사 전력

        확인 케이블·커넥터 체결, 매칭 박스와 전극 연결부의 풀림·탄 흔적

        조치 다시 체결하거나 교체

      • 제너레이터 출력·인터록 RF 전원 장치 패널

        점화 실패

        확인 제너레이터가 실제로 포워드 전력을 내보냈는지, 인터록(뚜껑·냉각수 등)으로 막히지 않았는지

        조치 인터록이 걸린 원인부터 해결

      • 샤워헤드 구멍·가장자리 아킹 샤워헤드 패널

        아킹반사 전력

        확인 반사 전력·전압 로그에 순간적으로 튀는 값, 구멍 가장자리 변색·침식, 파티클·결함 증가 시점과 겹치는지

        조치 세정, 침식이 심하면 교체 검증 필요

      • 쌓인 막·이물, 접지 경로 공정 챔버 패널

        아킹반사 전력

        확인 세정 주기, 벽·샤워헤드에서 벗겨진 날카로운 이물, 히터 쪽 접지 경로 검증 필요

        조치 RPS 세정, 세정 주기 조정

      • 매칭·제너레이터 자체 RF 전원 장치 패널

        마지막에

        확인 위의 것을 모두 확인한 뒤에도 남으면

        조치 매칭 네트워크 부품(커패시터·모터)이나 제너레이터를 교체 시험으로 좁힘

    4. 04 · 조치 후 확인

      점화·반사 전력·튜닝 위치가 평소 범위인지 본다

      테스트 레시피로 점화가 바로 되는지, 반사 전력이 평소처럼 낮은지, 튜닝 위치가 평소 범위에 있는지 확인한 뒤 테스트 웨이퍼로 두께와 결함을 봅니다.

    D막질 이상굴절률이나 막 응력이 기준에서 벗어남

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 어느 값이 어느 방향으로 벗어났나요? (굴절률 높음/낮음, 응력 인장/압축 쪽)
    • 같은 웨이퍼의 두께·균일도는 정상인가요?
    • 어느 PM인가요? 같은 레시피의 다른 PM은요?
    • 최근 가스 교체, MFC·히터·매칭 교체, 레시피 변경이 있었나요?
    • 같은 측정 장비로 잰 값인가요?

    1. 01 · 범위

      한 챔버만인가, 여러 챔버인가

      한 챔버만 → 그 PM의 온도(히터), RF(전력·저주파 비율), 그 PM으로 가는 MFC

      여러 챔버 → 레시피 변경, 공용 가스 공급(가스 교체·공급 압력), 측정 장비 검증 필요

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → MFC·히터·매칭 교체 직후, 가스 교체, RPS 세정 직후(시즈닝)

      서서히 → MFC 드리프트, 온도 센서 드리프트, 챔버 안 쌓임 검증 필요

    3. 03 · 원인 후보 → 확인 → 조치

      "무엇이 벗어났나"로 변수를 거꾸로 찾는다 (공정변수의 경향)

      • 굴절률 → 가스 비율 (MFC) 가스 박스 패널

        굴절률

        확인 굴절률은 막 조성(실리콘과 질소의 비)을 따라감 → 원료 가스마다 MFC 표시값과 셋포인트, 영점, 유량 검증

        조치 MFC 보정 또는 교체

      • 응력 → RF 전력·저주파 비율 RF 전원 장치 패널

        응력

        확인 응력은 이온 충돌을 따라감 → 실제로 들어간 전력(포워드 − 반사), 제너레이터 출력 보정, 매칭 상태 검증 필요

        조치 출력 보정, 매칭 점검

      • 응력·수소·밀도 → 히터 온도 공정 챔버 패널

        응력굴절률

        확인 영역별 온도 읽음값과 열전대 상태

        조치 센서·히터 점검, 필요하면 교체 검증 필요

      • 압력 → 스로틀 밸브·압력계 공정 챔버 패널

        응력

        확인 스로틀 밸브 열림 값 추이, 압력계 영점

        조치 압력계 보정, 배기 쪽 막힘 해결

      • 세정 직후 첫 몇 장만 공정 챔버 패널

        둘 다

        확인 시즈닝을 정해진 대로 했는지, 몇 장 뒤 평소 값으로 돌아오는지 검증 필요

        조치 시즈닝 레시피 확인

    4. 04 · 조치 후 확인

      굴절률·응력·두께를 함께 다시 잰다

      변수는 서로 얽혀 있어서 하나를 고치면 다른 값이 움직일 수 있습니다(공정변수: 얽힘). 다른 PM과 비교해 함께 기준 안에 들어온 것을 확인합니다.
