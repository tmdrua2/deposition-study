문제와 점검

부품부터 뜯어보지 않습니다. 범위 → 시점 → 원인 나누기 → 조치 순서로 의심할 곳을 좁힙니다. 위에서 틀을 익히고, 맨 아래 점검 게임에서 직접 좁혀 보세요.

    모든 문제에 쓰는 네 칸 점검 틀

    증상이 달라도 처음 몇 단계는 같습니다. 스크롤하면 단계마다 살펴볼 계통이 계통도에서 켜지고, 고리가 의심할 부품을 가리킵니다. 대표적인 점검 순서이고 실제 판단 기준은 장비·회사마다 다릅니다 검증 필요.

    한 곳만인가?

    한 챔버만 이상하면 그 챔버에만 있는 것 — 히터, ALD 밸브, 펌핑 링 — 을 먼저 봅니다.

    모든 챔버가 함께 이상하면 함께 쓰는 것 — 전구체 공급부, 레시피, 측정 장비 — 을 먼저 봅니다. 그림의 챔버는 TM 둘레 네 챔버 중 하나입니다.

    메모: 비교 대상이 있으면 빨라진다

    같은 레시피를 쓰는 다른 챔버가 정상이면 그것이 가장 좋은 기준입니다. 이상한 챔버와 정상 챔버의 로그(온도·압력·밸브 개폐)를 나란히 놓고 다른 값을 찾습니다.

    전구체 용기를 챔버마다 따로 두는지, 여러 챔버가 나눠 쓰는지는 장비마다 다릅니다 검증 필요. 그래서 "함께 쓰는 것"이 무엇인지 장비 구성부터 확인합니다.

    공정 챔버 패널전구체 공급부 패널장비 구성 계통도

    2 / 4

    갑자기인가, 서서히인가?

    갑자기 생겼으면 그 시점에 바뀐 것 — 정비·부품 교체, 전구체 용기 교체, 레시피 변경, 알람 — 을 찾습니다.

    서서히 나빠졌으면 쌓이거나 닳는 것 — 펌핑 링·벽에 쌓인 막, 줄어드는 전구체 잔량, 밸브 개폐 횟수, 배관 응축 — 을 봅니다.

    메모: 기록이 시점을 알려 준다

    정비 기록·알람 기록·마지막 세정 이후 처리 장 수를 증상이 시작된 날짜와 맞춰 봅니다. 날짜가 겹치는 일이 첫 번째 후보입니다.

    ALD 밸브는 사이클마다 열고 닫혀 개폐 횟수가 매우 많습니다. 서서히 나빠지는 문제라면 개폐 횟수를 수명 기준과 비교합니다 검증 필요.

    ALD 밸브 패널펌핑 링 (공정 챔버 패널)조작 화면 (기록)

    원인 나누기: 어느 길의 문제인가

    장비를 공급 · 진공 배기 · 가열 제어 · 이송 네 길로 나누고, 로그와 측정 결과로 후보를 하나씩 지웁니다.

    예: 사이클당 두께가 변했다 → 공급(전구체 양·퍼지)과 가열(웨이퍼 온도). 파티클이 늘었다 → 공급(퍼지 부족·밸브 누설), 챔버 벽, 이송 길.

    메모: ALD에서 먼저 의심하는 두 가지

    퍼지 부족: 남은 전구체와 반응 기체가 공중에서 만나 CVD처럼 반응하면 두께가 늘고 파티클이 생길 수 있습니다 검증 필요.

    온도가 창 밖: 너무 낮으면 응축·반응 부족, 너무 높으면 전구체 분해·이탈로 성장이 달라집니다(ALD 온도 창).

    퍼지 공급부 패널히터 (공정 챔버 패널)공정변수

    조치와 확인

    원인 부품을 고친 뒤 테스트 웨이퍼를 같은 레시피로 돌려 두께·균일도·파티클을 다시 잽니다.

    정상 챔버·이전 기록과 같은 수준으로 돌아온 것을 확인하고 생산을 다시 시작합니다. 원인과 조치는 기록으로 남깁니다.

    메모: 고쳤다고 끝이 아니다

    챔버를 열었다면 누설 검사와 펌프 다운 시간을 먼저 확인합니다. 세정 뒤에는 첫 몇 장이 평소와 다를 수 있어 더미 웨이퍼를 먼저 돌리기도 합니다 검증 필요.

    같은 증상이 다시 나오면 고친 부품이 원인이 아니었을 수 있습니다. 지운 후보와 남은 후보를 기록해 두면 다음 점검이 빨라집니다.

    아래 점검 게임공정 흐름 (웨이퍼 경로)

    점검 게임: 후보를 좁혀 보세요

    고객사에서 증상을 알려 왔습니다. 증상 → 범위 → 시점을 차례로 고르면 계통도에 후보 부품이 번호 고리로 켜지고 목록이 좁혀집니다. 마지막에 확인 방법과 조치를 봅니다.

    1어떤 증상인가요?

    2어디서 생기나요?

    3언제부터인가요?

    증상별 점검 순서

    게임에서 본 내용을 증상마다 한 번에 펼쳐 봅니다. 원인 후보 이름을 누르면 장비 페이지에서 그 부품 패널이 열립니다. 후보 옆 작은 표시는 "어떤 범위·시점일 때 의심하나"입니다.

    A두께 불균일웨이퍼 안 두께 차이가 커짐 (가장자리·한쪽이 두꺼움)

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 어느 챔버에서, 언제부터인가요?
    • 두께 맵 모양은요? (가운데·가장자리·한쪽 치우침, 기체가 들어오는 쪽이 두꺼운지)
    • 최근 정비·부품 교체·용기 교체·레시피 변경이 있었나요?
    • 같은 측정 장비로 잰 값인가요?

    1. 01 · 범위

      한 챔버만인가, 모든 챔버인가

      한 챔버만 → 그 챔버의 히터 온도 분포, 웨이퍼 놓임, 펌핑 링, 샤워헤드

      모든 챔버 → 함께 쓰는 전구체 공급·레시피·측정 장비

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 정비 뒤 웨이퍼 위치·히터 교체, 레시피 변경

      서서히 → 펌핑 링·샤워헤드에 쌓인 막, 전구체 잔량 감소

    3. 03 · 원인 후보 → 확인 → 조치

      두께 맵 모양과 정비 이력을 함께 보고 좁힌다

      • 히터 온도 분포 공정 챔버 패널

        확인 영역별 온도 읽음값과 열전대(온도 센서). 온도가 온도 창 가장자리에 걸리면 작은 온도 차이도 두께 차이로 나타날 수 있음 검증 필요

        조치 센서·히터 점검, 필요하면 교체 후 테스트 웨이퍼

      • 웨이퍼 놓임 위치 트랜스퍼 모듈 패널

        확인 정비 뒤부터라면 진공 로봇이 히터 중심에 평평하게 놓는지(티칭), 리프트 핀 높이

        조치 로봇 티칭·핀 높이 다시 맞춤

      • 펌핑 링·배기 포트 막 쌓임 공정 챔버 패널

        확인 스로틀 밸브가 같은 압력에서 평소보다 많이 열려 있는지, 마지막 세정 이후 처리 장 수 검증 필요

        조치 펌핑 링·배기 경로 세정

      • 전구체 양 부족 (포화 안 됨) 전구체 공급부 패널

        확인 기체가 먼저 닿는 쪽만 두꺼운 맵인지, 용기 잔량·용기 온도 기록 검증 필요

        조치 용기 교체 또는 펄스 시간을 늘려 포화되는지 확인(공정변수)

      • 퍼지 부족 → 기체가 섞임 ALD 밸브 패널

        확인 퍼지 시간·퍼지 유량 변경 기록. 섞이면 CVD처럼 한쪽이 더 쌓임 검증 필요

        조치 C. 증착 속도가 높음 흐름으로

      • 샤워헤드 구멍 막힘 공정 챔버 패널

        확인 얇은 영역이 특정 구멍 영역과 겹치는지 검증 필요

        조치 세정, 복구되지 않으면 교체

      • 레시피·측정 장비 조작 화면 패널

        확인 모든 챔버가 같은 날부터라면 레시피 변경 이력, 측정 장비 보정 이력

        조치 변경 전 레시피와 비교, 측정 장비를 기준 웨이퍼로 확인

    4. 04 · 조치 후 확인

      테스트 웨이퍼로 여러 점 두께를 다시 잰다

      정상 챔버·이전 기록과 같은 균일도로 돌아왔는지 확인한 뒤 생산을 다시 시작하고, 원인과 조치를 기록합니다.

    B파티클 증가웨이퍼 위 입자·결함 수가 평소보다 많음

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 파티클 맵에서 어디에 몰리나요? (가장자리·특정 위치·전체)
    • 장비에 들어가기 전 측정값과 비교했나요?
    • 공정 없이 이송만 한 웨이퍼도 늘었나요?
    • 마지막 세정 뒤 몇 장째인가요? 최근 챔버를 연 정비나 용기 교체가 있었나요?

    1. 01 · 범위

      한 챔버만인가, 웨이퍼가 함께 지나는 길 전체인가

      한 챔버만 → 그 챔버의 벽·뚜껑에 쌓인 막, 밸브 누설, 차가운 곳, 최근 연 정비

      모든 챔버 → 이송 길(진공 쪽 LL·TM과 대기 쪽 EFEM을 나눠서), 공용 전구체 배관

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 정비·용기 교체 직후, 히터 고장, 펌프 정지

      서서히 → 벽에 쌓인 막이 두꺼워져 벗겨짐 검증 필요

    3. 03 · 원인 후보 → 확인 → 조치

      이송만 한 웨이퍼와 공정한 웨이퍼를 비교해 길을 나눈다

      • 벽·뚜껑에 쌓인 막 벗겨짐 공정 챔버 패널

        확인 마지막 세정 이후 누적 두께·처리 장 수, 파티클이 막 조각 모양인지 검증 필요

        조치 챔버 세정(방법은 장비마다 다름), 세정 주기 다시 정하기 검증 필요

      • 퍼지 부족·밸브 누설 → 공중 반응 ALD 밸브 패널

        확인 퍼지 시간 변경 기록, 밸브를 닫은 채 압력이 오르는지(누설 검사)

        조치 퍼지 시간 되돌림 또는 밸브 교체 후 파티클 측정

      • 챔버 벽·뚜껑의 차가운 곳 (응축) 공정 챔버 패널

        확인 벽·뚜껑·밸브 블록 히터 온도 기록, 꺼진 구간이 있는지

        조치 히터 수리 후 쌓인 것 청소 검증 필요

      • 챔버를 연 정비 직후 공정 챔버 패널

        확인 오링(고무 밀봉)·뚜껑 닫을 때 들어간 이물, 누설 검사·펌프 다운 시간

        조치 세정 후 더미 웨이퍼 몇 장, 다시 측정

      • 이송 길 (로드락·TM·EFEM) 로드락 패널

        확인 이송만 한 웨이퍼도 늘었는지. 진공 쪽(로드락 벤트·펌핑 속도, TM)과 대기 쪽(EFEM 필터·양압)을 나눠서

        조치 원인 모듈 정비 후 이송만 한 웨이퍼로 다시 확인

      • 펌프 정지 뒤 역류 드라이 펌프 패널

        확인 펌프 트립(갑자기 멈춤) 기록과 증상 시작 시점이 겹치는지 검증 필요

        조치 펌프 점검, 챔버 세정

      • 용기 교체 뒤 배관 오염 전구체 공급부 패널

        확인 용기 교체 뒤부터인지, 교체 때 배관 퍼지·누설 검사를 정해진 대로 했는지 검증 필요

        조치 배관 퍼지 다시, 필요하면 필터·배관 교체

    4. 04 · 조치 후 확인

      이송만 한 웨이퍼와 공정한 웨이퍼로 다시 잰다

      두 가지 모두 평소 수준이면 생산을 다시 시작합니다. 세정 주기를 바꿨다면 그 뒤 몇 주 동안 추이를 지켜봅니다.

    C증착 속도가 예상보다 높음같은 사이클 수인데 더 두꺼움 — 퍼지 부족 의심

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 사이클당 두께가 얼마나, 언제부터 늘었나요?
    • 처리량을 올리려고 퍼지 시간을 줄인 적이 있나요?
    • 두께와 함께 균일도·파티클도 나빠졌나요?
    • 히터 온도·용기 온도를 바꾼 적이 있나요?

    1. 01 · 범위

      한 챔버만인가, 모든 챔버인가

      한 챔버만 → 그 챔버의 밸브 누설, 히터 온도, 배기

      모든 챔버 → 레시피(퍼지 시간), 공용 퍼지 가스·전구체 용기 온도

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 레시피 변경, 온도 설정 변경, 밸브 교체

      서서히 → 퍼지 유량 드리프트, 배기가 약해짐, 밸브 마모

    3. 03 · 원인 후보 → 확인 → 조치

      퍼지 시간을 늘려 봐서 두께가 줄면 퍼지 부족 쪽 검증 필요

      • 퍼지 시간이 짧아진 레시피 조작 화면 패널

        확인 레시피 변경 이력. 퍼지 시간을 늘려도 사이클당 두께가 그대로면 퍼지는 충분한 것

        조치 퍼지 시간을 포화 구간 안으로 되돌림

      • 퍼지 유량 부족 (MFC) 반응 기체·퍼지 공급부 패널

        확인 퍼지 MFC(질량 유량 제어기) 표시값과 목표값 차이, 유량 검증 검증 필요

        조치 MFC 보정 또는 교체

      • 밸브가 덜 닫힘·누설 ALD 밸브 패널

        확인 닫힌 상태에서 전구체가 새는지(누설 검사), 개폐 횟수 기록

        조치 밸브 교체 후 두께·파티클 확인

      • 웨이퍼 온도가 창보다 높음 공정 챔버 패널

        확인 히터 온도 기록·열전대. 창보다 높으면 전구체가 스스로 분해해 더 쌓일 수 있음

        조치 온도 설정·센서 점검 (온도 창)

      • 배기가 약해 늦게 빠짐 드라이 펌프 패널

        확인 퍼지 동안 압력이 평소처럼 빨리 떨어지는지, 스로틀 열림 값, 펌핑 링 막힘 검증 필요

        조치 배기 경로 세정·펌프 점검

      • 용기·배관이 너무 뜨거움 전구체 공급부 패널

        확인 용기·가열 배관 온도 설정 변경, 전구체가 배관에서 분해할 만큼 높은지 검증 필요

        조치 온도 설정 되돌림, 배관 점검

    4. 04 · 조치 후 확인

      사이클당 두께가 기준으로 돌아왔는지 잰다

      퍼지 시간을 바꿔 가며 두께가 더 줄지 않는 지점(포화)을 확인하고, 균일도·파티클도 함께 봅니다.

    D막이 기대만큼 안 쌓임같은 사이클 수인데 더 얇음 — 전구체 소진·온도 저하 의심

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 얇아진 것이 갑자기인가요, 조금씩인가요?
    • 전구체 용기는 언제 교체했고 지금 얼마나 썼나요?
    • 같은 용기를 쓰는 챔버가 모두 얇아졌나요?
    • 히터·용기 온도 알람이 있었나요?

    1. 01 · 범위

      한 챔버만인가, 모든 챔버인가

      한 챔버만 → 그 챔버의 히터 온도, 밸브 응답

      모든 챔버 → 전구체 용기(잔량·온도), 운반 가스, 레시피

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 용기 교체 직후(덜 데워짐), 히터 고장, 레시피 변경

      서서히 → 전구체 잔량 감소, 배관 부분 막힘, 밸브 마모

    3. 03 · 원인 후보 → 확인 → 조치

      펄스 시간을 늘려 봐서 두께가 회복되면 공급 부족 쪽 검증 필요

      • 전구체 잔량 소진 전구체 공급부 패널

        확인 용기 사용량·교체 시기, 같은 용기를 쓰는 챔버가 모두 얇아졌는지

        조치 용기 교체 후 첫 웨이퍼 두께 확인

      • 용기 온도가 낮음 전구체 공급부 패널

        확인 용기 히터 온도 기록. 용기가 덜 데워지면 증기가 적게 나와 한 번에 들어가는 양이 줄어듦. 교체 직후라면 데워질 시간이 충분했는지 검증 필요

        조치 히터 점검, 온도가 안정된 뒤 다시 시작

      • 운반 가스 유량 전구체 공급부 패널

        확인 전구체 증기를 실어 나르는 운반 가스 MFC 표시값과 목표값 검증 필요

        조치 MFC 보정·교체

      • 웨이퍼 온도가 창보다 낮음 공정 챔버 패널

        확인 히터 온도·열전대. 창보다 낮으면 반응이 끝까지 가지 않아 덜 쌓일 수 있음

        조치 히터·센서 점검 (온도 창)

      • 밸브가 늦게 열림 ALD 밸브 패널

        확인 밸브 개폐 시간 기록, 개폐 횟수 검증 필요

        조치 F. 밸브 응답 이상 흐름으로

      • 전구체 배관 부분 막힘 전구체 공급부 패널

        확인 배관 구간별 온도, 같은 조건에서 압력 변화가 평소와 다른지

        조치 E. 배관 막힘·응축 흐름으로

      • 펄스 시간이 짧아진 레시피 조작 화면 패널

        확인 레시피 변경 이력

        조치 포화 구간 안으로 되돌림

    4. 04 · 조치 후 확인

      사이클당 두께가 기준으로 돌아왔는지 잰다

      펄스 시간을 늘려도 두께가 더 늘지 않으면 포화된 것입니다. 용기를 바꿨다면 잔량 관리 기준도 다시 봅니다.

    E전구체 배관 막힘·응축배관·밸브 안에 전구체가 식어 붙거나 가루가 쌓임

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 배관 온도 알람이나 히터 재킷(배관을 감싼 히터) 이상 기록이 있나요?
    • 용기를 바꾸거나 배관을 연 작업이 최근에 있었나요?
    • 두께가 줄거나 파티클이 함께 늘었나요?
    • 용기·배관·밸브 블록 온도 설정을 바꿨나요?

    1. 01 · 범위

      한 챔버로 가는 배관만인가, 공용 구간인가

      한 챔버만 → 그 챔버의 밸브 블록 온도, 퍼지, 배기

      모든 챔버 → 용기 온도 설정, 공용 배관 히터, 용기 교체 작업

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 히터 재킷 고장, 용기 교체 때 공기·수분 유입, 온도 설정 변경

      서서히 → 조금 차가운 곳에 응축이 조금씩 쌓임

    3. 03 · 원인 후보 → 확인 → 조치

      용기 → 배관 → 밸브 → 챔버 순서로 온도를 따라가 차가운 곳을 찾는다

      • 가열 배관의 차가운 곳 전구체 공급부 패널

        확인 구간별 온도, 히터 재킷이 끊기거나 벗겨진 곳, 용기보다 차가운 구간 검증 필요

        조치 히터 수리 후 배관 청소·교체

      • 밸브 블록 온도가 낮음 ALD 밸브 패널

        확인 밸브 블록 히터 온도, 같은 장비의 다른 챔버와 비교

        조치 히터 점검, 밸브 청소·교체

      • 용기가 배관보다 뜨거움 전구체 공급부 패널

        확인 용기 온도 설정을 올렸는지. 용기보다 차가운 배관에서는 증기가 응축할 수 있음 검증 필요

        조치 용기 → 배관 → 밸브로 갈수록 같거나 조금 따뜻하게 다시 맞춤 검증 필요

      • 퍼지 부족 → 밸브 근처에서 두 기체가 만남 ALD 밸브 패널

        확인 쌓인 것이 막·가루인지, 퍼지 시간·유량 검증 필요

        조치 청소 후 퍼지 조건 확인

      • 용기 교체 때 공기·수분 유입 전구체 공급부 패널

        확인 교체 직후부터인지, 교체 뒤 누설 검사·배관 퍼지 기록. 공기·수분과 반응하는 전구체가 있음 검증 필요

        조치 장비를 안전하게 멈추고 배관 퍼지·청소, 연결부 다시 조임

      • 배기 쪽 막힘과 구분 드라이 펌프 패널

        확인 막힌 곳이 공급 쪽(밸브 앞)인지 배기 쪽(스로틀·포어라인)인지 — 압력이 어디서 달라지는지 검증 필요

        조치 배기 쪽이면 포어라인 청소·펌프 점검

    4. 04 · 조치 후 확인

      온도가 고르게 돌아온 뒤 테스트 웨이퍼를 돌린다

      구간별 온도가 설정대로인지, 두께·파티클이 기준인지 확인합니다. 전구체를 다루는 작업은 안전 절차(퍼지·보호구)를 지킵니다.

    F밸브 응답 이상ALD 밸브가 늦게 열리거나 덜 닫힘

    CS 엔지니어가 고객에게 먼저 물어볼 것

    • 어느 챔버의 어느 밸브인가요? 한 개인가요, 여러 개인가요?
    • 밸브 교체 뒤 개폐 횟수는 얼마나 되나요?
    • 구동 공기(밸브를 움직이는 압축 공기) 압력 알람이 있었나요?
    • 두께가 줄었나요(늦게 열림), 파티클·두께가 늘었나요(덜 닫힘)?

    1. 01 · 범위

      한 밸브만인가, 여러 밸브인가

      한 챔버만 → 그 밸브 자체, 그 밸브의 신호선·솔레노이드(전기로 공기를 여닫는 작은 밸브)

      모든 챔버 → 함께 쓰는 구동 공기 공급, 제어기

    2. 02 · 시점

      갑자기인가, 서서히인가

      갑자기 → 밸브 교체·배선 작업 직후, 구동 공기 압력 변화

      서서히 → 개폐 횟수가 쌓인 마모, 밸브 안 응축

    3. 03 · 원인 후보 → 확인 → 조치

      증상이 "늦게 열림"인지 "덜 닫힘"인지 먼저 나눈다

      • 개폐 횟수 누적 → 마모 ALD 밸브 패널

        확인 개폐 횟수 기록을 수명 기준과 비교 검증 필요

        조치 밸브 교체, 교체 주기 다시 정하기

      • 구동 공기 압력 ALD 밸브 패널

        확인 공용 구동 공기 압력·레귤레이터·필터. 여러 밸브가 함께 느려졌다면 먼저 의심 검증 필요

        조치 공기 공급 정상화 후 개폐 시간 다시 확인

      • 제어 신호·배선·솔레노이드 조작 화면 패널

        확인 제어기가 보낸 신호와 밸브가 실제로 움직인 기록이 맞는지, 배선 작업 이력

        조치 배선·솔레노이드 점검·교체

      • 밸브 안 응축·쌓임 ALD 밸브 패널

        확인 밸브 블록 온도, 밸브를 열어 쌓인 것 확인

        조치 E. 배관 막힘·응축 흐름으로

      • 교체 직후 조립·설정 ALD 밸브 패널

        확인 새 밸브의 연결·조임, 누설 검사 결과, 개폐 시간 설정

        조치 다시 조립하고 누설 검사

    4. 04 · 조치 후 확인

      누설 검사 → 개폐 시간 → 테스트 웨이퍼

      밸브가 새지 않고 정해진 시간 안에 열리고 닫히는지 본 뒤, 두께·파티클을 재서 기준과 비교합니다.

    네 칸 점검 틀

    1. 한 곳만인가 — 한 챔버면 그 챔버, 모든 챔버면 함께 쓰는 것
    2. 갑자기인가 — 갑자기면 그때 바뀐 것, 서서히면 쌓이고 닳는 것
    3. 원인 나누기 — 공급·진공 배기·가열 제어·이송 중 어느 길인지
    4. 조치와 확인 — 테스트 웨이퍼로 확인하고 기록

    ALD에서 자주 보는 짝

    • 두께가 늘면 → 퍼지 부족·밸브 누설·온도 높음
    • 두께가 줄면 → 전구체 소진·용기·웨이퍼 온도 낮음·밸브 늦음
    • 파티클 → 공중 반응·벽 막 벗겨짐·응축·이송 길
